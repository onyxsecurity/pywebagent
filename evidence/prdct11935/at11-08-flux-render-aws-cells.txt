=== WHAT THAT DELTA IS, AND WHY IT IS STILL NOT A BEHAVIOUR CHANGE ===
    Three things, all of them config TEXT:
      (a) two ASB stanzas ADDED to endpoint-asset-ingestion's config.yaml, both entirely empty. Empty
          is exactly what the model already defaults them to, and every branch that reads them tests
          for a NON-empty queue_name, so an empty stanza and an absent stanza are the same config.
      (b) the two empty gen-2 *_asb stanzas REMOVED. Their model fields are gone with the dead Azure
          branch; BaseCustomSettings sets extra="allow", so a cell whose values still carry the key
          boots and ignores it either way (measured in at10-22 section 4.2).
      (c) a checksum/config annotation change, which is helm's deploy trigger. The one real operational
          consequence of this PR on an AWS cell is therefore a SINGLE ROLLING RESTART of
          endpoint-asset-ingestion (and, on s-use1-c01, of the two gen-2 consumers) when the chart
          lands — a redeploy, not a behaviour change. Saying so plainly is the point of this section.

    The strongest form of (a): take the REAL rendered config.yaml off c03/saas's head manifest, fill
    the terraform placeholders with that cell's values, and construct the HEAD config model from it.
    If the head chart broke an AWS cell, it breaks here.
        the rendered AWS-cell config CONSTRUCTS on the head model: cloud=aws
          asset_ingestion_sqs.queue_url = https://sqs.us-east-1.amazonaws.com/1234/endpoint-asset-ingestion

=== the Azure instances render 0-diff too, which is not a contradiction ===
    c02/saas and c02/centerpoint set asset_ingestion_asb to REAL values in their own flux-fleet
    instance values (fully_qualified_namespace: ${endpoint_asset_ingestion_servicebus_namespace}).
    Helm renders config.yaml from the merged values map, so an instance-supplied key renders whether
    or not the chart declares a default for it — the Azure lane never depended on the chart defaults,
    which is also why removing them would NOT have been a way to make the AWS delta vanish for free.
    The chart defaults are documentation of the knob, and the owner's KEEP list names them.
