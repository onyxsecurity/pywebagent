=== 3. WHAT IT ACTUALLY IS: a per-object authoritative write, and eight objects ===
    metadata.sources is written by replace_scan_connection_sources (mcp_writer.py) — 'authoritatively
    overwrite metadata.sources on every connection observed this scan ... runs once per object'. An
    edge named by more than one object of the same scan therefore ends up with whatever the LAST
    object to land says. Three of the eight replayed payloads name the Context7 edge:
      01.json  (641547 bytes)
      05.json  (1055077 bytes)
      07.json  (1132513 bytes)
    So the surviving order is a function of object ARRIVAL ORDER, which two pool workers racing over
    an SQS queue decide — not of the writer's logic, which this PR does not touch
    (mcp_writer.py and source_attribution.py have zero hunks: see at11-01's hunk map).
