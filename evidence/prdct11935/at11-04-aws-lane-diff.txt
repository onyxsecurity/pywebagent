=== 5. THE PREVIOUS REVISION'S RAW 8-LINE DELTA IS SUPERSEDED, AND HERE IS WHY ===

    The revision of this file dated 2026-08-23T17:32Z reported a RAW 8-line base-vs-head delta and
    defended it with a normalised 0-line comparison.  THAT DEFENCE IS NO LONGER THE PROOF AND SHOULD
    NOT BE CITED.  The raw diff is now 0 because the cause of those 8 lines has been REMOVED from the
    experiment, not normalised away.

    What the 8 lines were: the element ORDER inside one connection's `metadata.sources` JSON array, on
    five rows.  `replace_scan_connection_sources` authoritatively overwrites metadata.sources once per
    OBJECT, so an edge named by more than one object of the same scan ends up with whatever the LAST
    object to land says.  Three of the eight replayed bodies name the Context7 edge.  With eight
    objects racing through a queue and a pool of workers, which lands last is a coin flip — the old
    capture was measuring delivery order, not the image.  That arrival-order dependence is PRE-EXISTING
    and UNCHANGED BY THIS PR (`mcp_writer.py` and `source_attribution.py` both carry 0 lines of
    merge-base..head diff — re-verified for this capture).

    What removed it: the replay is now SETTLE-GATED SEQUENTIAL.  Body N+1 is not POSTed until body N's
    object has landed in the leg bucket, the leg queue reads 0 visible AND 0 in-flight, and the leg
    writer has logged its Nth `outcome=processed`.  Arrival order is therefore forced to 01..08 on both
    legs, identically, and the field has nothing left to race over.  The five rows that used to differ
    are now character-for-character equal on the two legs:
