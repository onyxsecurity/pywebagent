=== 3. THE FORMATTER IS DAY-GRANULAR (no time component) ===
  frontend/app/src/lib/format.ts
      // midnight UTC, so these render the UTC calendar date. Local-tz rendering of a midnight-UTC
      // value would show the previous day anywhere west of UTC (and a time-of-day is meaningless).
      export const formatUtcDateYearMonthLongDay = createDateFormatter({
        year: "numeric",
        month: "short",
        day: "numeric",
        timeZone: "UTC",
      });
      
  year/month/day only, timeZone UTC — so two rows whose updated_at differ by minutes or hours render
  the SAME string. The uninstalled runtime and every still-installed control on the same machine show
  an IDENTICAL "Last Seen" value on the same calendar day.
